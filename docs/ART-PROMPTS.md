# Office art prompts

Art for this layout is **generated by `tools/build-art.py`** as placeholders:
flat pixel blocks drawn in code, no image model, no third-party assets, so
`herdr-app check` and the layout itself work out of the box.

To replace them with generated art, keep the filename and pixel size — the mods
reference them by name — and use the prompts below. Green screen (`#00FF00`)
backgrounds get cut out afterwards, same as the upstream Traveler kit.

## Sizes

| File | Size | Notes |
|---|---|---|
| `mods/office-agents/art/<role>.png` | 256x256 | 8 role busts, transparent |
| `mods/office-agents/sprites/<role>-<state>.gif` | 144x192 | `state` = `working` \| `rest` \| `blocked`, transparent, looping |
| `mods/office-spaces/art/<place>.png` | 256x256 | 4 buildings, transparent |
| `mods/office-tabs/art/<kind>.png` | 256x256 | `files`, `changes`, `inbox`, transparent |
| `mods/office-chrome/sidebar.png` | 460x1844 | full-height sidebar, `cover`-cropped |
| `mods/office-chrome/floor.png` | 1658x1224 | terminal background, low contrast |
| `layouts/office.png` | 640x468 | layout picker thumbnail |

Roles: `manager` (Claude Code), `developer`, `designer`, `analyst`, `writer`,
`tester`, `support`, `intern`.
Places: `hq`, `branch`, `studio`, `lab`.

## Sprites: one per role per state

Sprites are drawn by hand in code upstream, not by a model. If you generate them
instead, request a **full-body 3/4 view with a transparent background**, and keep
the same canvas: the card reserves 72x96 points, so anything wider than 36x48
art pixels gets cropped.

Common block:

```
Pixel art full-body character sprite, 36x48 logical pixels scaled up with hard square pixels, limited palette, modern office at night, sitting at a desk with two monitors, facing the viewer, centered, plain solid pure green background (#00FF00), no text, no border, no scenery.
```

Then one line per state:

```
working: hands on the keyboard, screen showing output, torso slightly forward.
rest: leaning back, eyes half closed, one hand on a coffee mug.
blocked: one arm raised straight up with an open palm, a bright red exclamation mark beside the head.
```

## Tuning

- Too painterly: prepend `strictly pixel art, visible square pixels, no smooth shading`.
- Background not flat: add `flat single color background, no gradient, no shadow on background`.
- Inconsistent style across a set: use the best result as a reference image and
  generate the rest in the same conversation.
- Floor too bright: add `darker, night tones, muted highlights`.
